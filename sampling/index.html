Palettes from a photograph

in the workshop · literature review

Load a photograph and get a pyramid of palettes: one colour, two, three… each row refining the one above, so the image's colour structure reads from coarse to fine.

What it will do:

  • A divisive tree in CIELAB (binary splitting) as the backbone, so the rows are nested.
  • Lineage lines between rows, like the connecting lines in the curves instrument.
  • Live readouts: reconstruction error and diversity (ΔE00) for each row, and the photo repainted with it.
  • Send any row to palette analysis, or plot it in the HSL cylinder.
