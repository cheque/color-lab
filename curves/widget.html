Palette picker widget

[the lab · Color Lab]

The same curve model as the lab, with the controls a picker needs and nothing else. Palettes are points on a continuous curve, so asking for twelve colors instead of seven is the same palette sampled finer — which is what the colors slider does.

Embedding

<script src="../lib/color.js"></script>
<script src="src/curve.js"></script>
<script src="../lib/reparam.js"></script>
<script src="../lib/palette.js"></script>
<script src="src/params.js"></script>
<script src="../lib/rangepair.js"></script>
<script src="src/widget.js"></script>

<div id="picker"></div>
<script>
  var picker = ColorCurves.mountPicker(
    document.getElementById('picker'), {
      onApply: function (palette) {
        // palette is a plain JS array of hex strings
        console.log(palette);   // ['#1b2a4a', '#2f5f7a', ...]
      }
    });
</script>

No stylesheet to link: the widget injects its own, scoped to .cc-widget.

Handle

picker.getPalette()   // ['#1b2a4a', ...]  — array of hex
picker.getParams()    // the parameters that made it
picker.getSource()    // a link that reopens exactly this curve
picker.setParams({N: 3, shape: 'pcircle'})
picker.destroy()

Or listen for the event

el.addEventListener('colorcurves:apply', function (e) {
  e.detail.palette;   // the same array
});
