sRGB
The same color, in every model

HSL, L*a*b* and L*C*h° are editable. Hue in HSL is a turn (0–1), as in the curves instrument; h° in L*C*h° is in degrees.

Reference white

10° observer (CIE 1964). The XYZ of an sRGB color is fixed by sRGB's own D65 white; the reference only changes how L*a*b* normalizes it, with no chromatic adaptation.
