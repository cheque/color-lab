# References

Every work cited in Color Lab's documents, in one list. Compiled 2026-11-14.

**Where cited:** S = [palette sampling review](../docs/literature-review-palette-sampling.md),
H = [color harmony review](../docs/literature-review-color-harmony.md), A = [palette analysis
spec](../docs/spec-palette-analysis.md), F = [random flights spec](../docs/spec-random-flights.md),
C = the code (`lib/color.js`, the instruments).

**Local copy:** the file name in `references/files/`. That folder is synced between the owner's computers
but **not committed** (`.gitignore`): the copies are for private reading, and their licenses do not all
allow redistribution from a public repository. Only open copies were downloaded: author or
institutional pages, arXiv, IPOL, Project Gutenberg, the Internet Archive and the Wellcome Collection
(public domain). Everything else is marked:

- **paywalled**: the publisher's copy only; get it through a library.
- **book**: a book still in copyright (or not digitized openly).
- **not found**: no open copy turned up in this search.

## Getting the paywalled ones

The priority is **Ou & Luo (2006)**: its coefficients are needed before the harmony instrument shows a
score. After that: Moon & Spencer (1944), Szabó et al. (2010), Orchard & Bouman (1991) and Heckbert
(1982). Through a university library, or by writing to the authors. Put the files in `references/files/` with
the same naming scheme (`author-year-short-title.pdf`) and update the table.
